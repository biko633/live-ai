# LIVE-AI

A mobile Android app that lets you chat with an AI companion featuring
multiple personalities and real-time voice interaction.

## 🚀 Overview

LIVE-AI is an AI-powered chat app built with React Native and Expo.\
Users can chat with intelligent chatbots, switch between different
personalities, and even have the bot talk back using realistic
AI-generated speech.
