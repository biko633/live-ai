# LIVE-AI

A mobile Android app that lets you chat with an AI companion featuring
multiple personalities and real-time voice interaction.

## 🚀 Overview

LIVE-AI is an AI-powered chat app built with React Native and Expo.
Users can chat with intelligent chatbots, switch between different
personalities, and even have the bot talk back using realistic
AI-generated speech.

## 🔑 API Keys Setup

### 1. Google Gemini API Key

Required for chatbot responses.
Get your API key here: https://aistudio.google.com/u/1/api-keys
Add it inside the app settings.
![demo google video](./google%20api%20key.gif)
### 2. ElevenLabs API Key (Optional)

Required if you want the bot to speak with AI-generated voice.
Get your key here: https://elevenlabs.io/app/home
![demo google video](./elevenlabs%20api%20key.gif)

## ⭐ Key Features

- 💬 Chat with an AI chatbot
- 🎭 Select from multiple bot personalities
- 🔊 AI voice responses (via ElevenLabs)
- ⚡ Fast and smooth UI built with Expo
- 📱 Easy one-tap APK installation

## 🛠 Tech Stack

- React Native
- Expo
- Google Gemini API
- ElevenLabs Text-to-Speech API
